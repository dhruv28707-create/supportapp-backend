SAFESPACE

Emotional support chat with 12 AI personalities — backend service.

All endpoints live under /api/* and speak JSON. Errors use the shape { "error": "message" }.

Choose your plan

New here? Start with 5 free days of Ultimate — no payment. When the trial ends, pick one:

EndpointAuthPurpose
GET /api/health none Liveness check.
GET /api/plans none Choice cards: free, Ultimate monthly, Ultimate yearly (prices included).
POST /api/trial/start Bearer token Start the 5-day Ultimate free trial (new accounts, once per account).
POST /api/chat Bearer token Chat with an AI persona. Body: { message, personality?, religionSubType? }.
GET /api/user/plan Bearer token Current plan and remaining messages.
POST /api/payment-order Bearer token Create a Razorpay order for a subscription tier.
POST /api/payment-verify Bearer token Verify a completed Razorpay checkout and activate the plan.
POST /api/payment-cancel Bearer token Cancel the active subscription (immediate). No body.
POST /api/webhooks/razorpay HMAC signature Razorpay webhook (server-to-server only).

Authentication uses a Firebase ID token: Authorization: Bearer <idToken>

See the repository README for the full API reference and setup guide.
